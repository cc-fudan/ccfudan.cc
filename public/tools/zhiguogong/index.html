    常见问题 · 离线可查

    “基础匹配”就一定能报吗？

    它表示已识别的条件通过本地规则初筛。专业映射、备注识别和年度通则均可能需要进一步核对，请打开岗位详情查看原文与咨询电话。

    函授本科、非全日制学历如何处理？

    工具不会仅因非全日制就排除。仍需核实学历认可、学位、取得时间及招录机关补充要求。学历和学位是两项不同条件。

    企业工作六年，算服务基层项目吗？

    普通工作经历与三支一扶、大学生村官等专项身份是不同条件。工作年限认定和专项身份分别填写，不能互相代替。

    审核通过人数为零，是否说明没有竞争？

    还需要看待审查人数、统计时间和审核进度。增强版仅在同一时点、同一来源有完整的通过及待审数据时，计算“当前可见申请压力”。它不是最终报录比。

    “生成求助材料”会消耗 API 吗？

    生成、复制和下载都在本机完成。你自行把材料发送给外部 AI 时，才会按该服务的规则消耗额度；本工具没有模型连接，也不收集密钥。

    把文件发给朋友，收藏会跟着走吗？

    收藏和条件保存在浏览器里，不会跟文件自动移动。请在数据管理中导出个人备份，再在另一版本或另一设备中恢复。清理浏览器前也应备份。

    理解匹配结果

    基础匹配：已填写的核心条件和已识别的限制通过检查，不代表最终可报。部分专业归类来自本地有限映射，仍需按目录和招录机关解释确认。

    待核对：条件未填、专业范围不明确，或备注含复杂资格要求。不会默认为符合。

    不符合：存在已识别的硬性冲突。每个职位可查看具体原因和原文。

    年龄规则默认关闭。当前文件没有完整年度报考通则；报名资格、学历证书取得时间、基层经历计算截止日、回避关系、在职身份限制等需要结合官方公告核实。

    非全日制/函授不自动排除，但需核实国家认可、学位、毕业时间和机关补充公告。专项项目身份不能用普通工作年限替代。

    报名快照来自手工录入或导入。只有相同口径可比较；快照超过24小时标记为旧数据。不同时间的快照可能有偏差，较低比例不代表更容易录取。
