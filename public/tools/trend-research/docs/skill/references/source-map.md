# 规则与实现定位

本页只定位项目内代码与算法配置，不发布阅读笔记、原始出版物、插图或第三方课程材料。

| 内容 | 文件 | 验证重点 |
|---|---|---|
| 输入与数学 | strategy/trading_math.py | 窗口、有限值、时间索引 |
| 日线入场与风险实验 | engine.py | 九项检查、账户完整性、仓位约束 |
| 研究解释与候选线 | research.py | 锚点、可知时间、穿越与反证 |
| 本地HTTP与账本 | app.py | 只读报告、独立成交、备份与修改历史 |
| 页面 | static/ | 文本转义、图层、研究结果展示 |
| 股评正文 | research.py:report_narrative | 结论、证据、变化、条件路径与行动 |
| 权利边界 | THIRD_PARTY_NOTICES.md | 软件许可不覆盖数据或第三方材料 |

通用公式、客观数据与项目特定实验参数需分别理解。未取得许可的第三方表达、数据或商标不得因去除名称而重新分发。后续集成依赖须保留其许可证要求的通知。

独立结构引擎：structures.py；两种严格拐点尺度、冻结几何、逐日状态机、修订代次、逐候选均线交叉。测试：tests/test_structures.py。
