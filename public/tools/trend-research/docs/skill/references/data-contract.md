# 输入与计算契约

CSV UTF-8列date,open,high,low,close,volume；amount可选且用报价币金额。日期YYYY-MM-DD严格递增；OHLC一致，价格有限正数、量额非负。至少125根与同日基准才能完整检查，截断不能泄露未来数据。

来源、复权、时区、完成状态、单位、提取时间和数据指纹须保留。未来截止日与非法数字拒绝。网页导入的当日日线须北京时间17:00后。公共端点是可选外部服务，许可证与商业使用范围由使用者核对。项目代码许可不授予数据再分发权。

记账币种CNY/HKD，费用、逐笔FX与真实成交价格独立记录。未提供账户、现金、完整持仓与执行资料时不计算个性化股数。部分卖出按移动平均成本分摊；超卖、非整数和倒序日期拒绝。净R只在风险基准可比时展示。

报告对比两次已保存扫描时，只能将前次快照日期之后的数据变化标作“本次新增”。历史回放结果与本机首次观察时间分列。行情重叠值、复权口径、历史回补、日期倒退或算法版本变化均另起代次并保留旧记录。
