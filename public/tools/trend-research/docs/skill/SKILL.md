# 趋势研究方法规范

本文件是软件算法契约。依次核对输入、基准、价格结构、指标方向、失效条件、执行约束及缺失信息。

- 读[规则规范](references/rulebook.md)复算V1实验，不为单笔结果临时换规则。
- 读[数据契约](references/data-contract.md)核对完成日期、币种、单位、复权与来源。
- 用[实现定位](references/source-map.md)定位代码；不把指标一致性包装成独立概率证据。
- 用[交易记录](assets/trade-record.md)分开保存买前理由、真实成交与事后复盘。

报告应给出：快照截止、候选线锚点和可知日期、趋势与量能解释、已知与反证、空仓/持仓条件情景、数据缺口和风险。研究信号不是订单；未执行退出不能假记成交。不能预测确定收益或复制他人文本。导出到外部AI之前核对隐私与使用许可。

完整股评采用证据先行的叙事结构：先给带日期的判断；回顾基准与价格如何演变到当前；解释结构前趋势、拐点、边界和最早可知时间；分别说明均线赞成或反对什么；有前次真实扫描时，只比较之后新增的事件；再列多条带触发和失效条件的路径；最后分开说明空仓与已有持仓的处理，补足数据和方法边界。事实、算法状态、解释和情景推演要区分。

没有活动结构就直说未检出，不为文章效果强行命名或虚构公告、基本面及资金意图。历史行情的机械回放不能写成实时发出的股评。Markdown导出以可读正文为主，参数、哈希和逐线记录放在审计附录。不得复制任何单篇文章的措辞、图表或个人叙事。


## 分析层1.4：独立结构研究

先独立运行structures.py识别双顶底、头肩顶底、水平区间及三类三角形，再与MA60/120和V1执行资格逐项交叉验证。结构锚点、颈线和边界在确认时冻结；逐根保留候选、收盘突破、后日回测、再后日守住、继续推进与失效/失败/到期记录。前趋势、反证和相反方向候选须展示；不输出胜率。结构自己的边界决定条件情景，不得被固定20日N/D取代。历史重建事件日期与本机首次观察时间分列；数据修订另起代次，旧代审计保留。查看报告只读；导入/刷新或显式扫描才保存研究快照。新结构不能改变V1价格/账户检查、已有账本或原保护价。详细参数与未覆盖范围见docs/research-method.md。
